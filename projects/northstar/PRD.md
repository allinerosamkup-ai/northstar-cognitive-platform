# Northstar — Product Requirements

## Product promise

Multiple LLMs cohabit one persistent cognitive project. They remain aware of the whole while working independently, collaboratively, or as a composite intelligence.

## Prototype acceptance

- One canonical append-only project context
- Three resident model families
- Continuous event awareness and stale-write protection
- Solo, distributed, parallel, joint, and composite work
- Provider-failure continuity
- Visual application, CLI, and Context API using the same project
- Durable state and traceable contributions
- Safe demo mode plus explicitly enabled live provider adapters

## Current boundary

This release is the validated cognitive-mesh prototype. Enterprise tenancy, production secret management, remote sandboxes, semantic vector retrieval, and governance controls remain later delivery phases.
